# KeenKeeper

KeenKeeper is a responsive friendship tracker web app that helps you keep relationships active by tracking contact gaps, logging quick check-ins, and visualizing interaction history.

## Live Links

- Live Site: https://mahmudunnabifahim29.github.io/B13-A7/
- GitHub Repository: https://github.com/mahmudunnabifahim29/B13-A7

## Technologies Used

- React 18
- React Router DOM
- Tailwind CSS
- Vite
- Recharts
- React Hot Toast
- Lucide React

## Key Features

1. Friend Dashboard
View friend cards with profile photo, contact status, tags, and days since last interaction.

2. Quick Check-In Timeline
Log Call, Text, and Video interactions from the friend details page and automatically build a timeline history.

3. Friendship Analytics
Analyze interaction types with a chart on the stats page and filter timeline entries by interaction type.
